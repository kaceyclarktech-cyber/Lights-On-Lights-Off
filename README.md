# Lights-On-Lights-Off
HTML web page that turns light bulbs on/off
# Features
Click a button to turn the bulb on or off

Smooth visual transition using CSS

Clean, minimal UI

Beginner‑friendly HTML/CSS/JS structure

No external libraries required
# Demo Preview
When the bulb is OFF, it appears dark.

When the bulb is ON, it glows with a bright yellow light.
